Фоновая работа и уведомления

Фоновый мониторинг работает отдельно через GitHub Actions. Он проверяет каналы из файла channels.txt примерно каждые 5 минут и отправляет push-уведомления через ntfy.

Cloudflare Worker и ADMIN_TOKEN не нужны. Чтобы изменить список каналов фонового мониторинга, открой channels.txt в GitHub. Для ручной проверки и запуска настроенных workflow используй GitHub Actions.
